# Figma skills — design system migration

Five slash commands for Figma's design agent that move a legacy design system onto a base kit such as Untitled UI **without changing what users see**, and prove it on real screens.

**Get them:** sold as a bundle with the Claude skill version. **[Buy the bundle on Gumroad — $19](https://rishikra4.gumroad.com/l/ds-migration)** · more on my [Tools page](https://rishik-jha.rishikrkjha.workers.dev/tools). How it was built: [case study](https://rishik-jha.rishikrkjha.workers.dev/case-study/design-system-migration).

| Command | When to run |
|---|---|
| `/ds-audit` | In the legacy design system file, before migrating. |
| `/ds-migrate` | In the base kit copy: foundations, then components. |
| `/ds-theme-mode` | When a second product needs its own look from the same library. |
| `/ds-validate-screen` | Rebuild one real screen beside its source and compare. |
| `/ds-coverage-test` | Validate 4–6 more screens to find the remaining gaps. |

Each command runs in the file it describes. Publishing the library and saving named versions stay manual.
